# Lingolumo 🦉

A Duolingo-inspired Spanish language learning application.

## Features
- Spanish learning path
- Multiple lesson types
- XP and daily XP
- Hearts and gems
- Streak tracking
- Lesson progression
- Mistake tracking
- Leaderboard
- Profile and settings

## Technology
- React 19 + TypeScript + Vite
- TanStack Router + React Query
- Tailwind CSS
- FastAPI + SQLAlchemy
- SQLite
